## Whole-system authority

Whole-system architecture and cross-project sequencing are owned by:

- https://github.com/aien-dev/aien-architecture/blob/main/PLAN_AUTHORITY.md
- https://github.com/aien-dev/aien-architecture/blob/main/CURRENT_EXECUTION_PLAN.md

- https://github.com/aien-dev/aien-architecture/blob/main/doctrine/ROADMAP.md

AIENOS must not create a competing whole-system master plan.

## AIENOS-local authority

Within this repository:

1. `ROADMAP.md` is the current AIENOS execution order and status.
2. `docs/ARCHITECTURE.md` is the current AIENOS component architecture.
3. `docs/adr/` records accepted AIENOS architectural decisions.
4. `docs/BLUEPRINT.md`, `docs/MILESTONES.md`, `docs/PHASE_3_TO_5_SPECIFICATION.md`, and `docs/SYSTEMS_INTEGRATION_SEQUENCE.md` are design/reference history. They do not override `ROADMAP.md` when sequencing has changed.

Implementation/evidence truth remains the current code and recorded qualification evidence.

If a reference document conflicts with the current roadmap or an accepted ADR, do not create another plan. Update the appropriate current authority and mark the older statement as historical.
